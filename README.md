# A Parsimonious Three-Dimensional Representation of Customer Behavioral Variability

## Overview

This repository accompanies the paper:

> **A Parsimonious Three-Dimensional Representation of Customer Behavioral Variability**

The study proposes a parsimonious customer representation based on three complementary behavioral descriptors:

- **Frequency**
- **Diversity**
- **Entropy**

Using the **Online Retail II** dataset, the proposed representation is evaluated through:

- descriptive analysis
- correlation analysis
- K-means clustering
- Kruskal–Wallis tests
- Dunn's post-hoc tests
- managerial validation using observed customer revenue
- comparison with a conventional Frequency–Diversity representation

The results demonstrate that incorporating **Entropy** provides additional behavioral information beyond purchasing intensity and portfolio breadth, leading to stronger differentiation of customer revenue across behavioral segments.

## Data

This study uses the **Online Retail II** dataset from the UCI Machine Learning Repository.

## Reproducibility

### 1. Download the Repository

Download this repository and extract it if necessary.

### 2. Prepare the Dataset

Follow the instructions in [`data/README.md`](data/README.md) to download the **Online Retail II** dataset and place the required Excel file in the `data/` directory.

### 3. Open the Project in RStudio

Open the repository as an R project.

If the repository contains the `.Rproj` file, open the project directly in RStudio.

Alternatively, in RStudio, select:

**File → New Project → Existing Directory → Browse**

and select the extracted `parsimonious-customer-representation` directory.

Opening the repository as an R project ensures that relative paths handled by `here()` resolve correctly.

### 4. Run the Analysis

To reproduce the complete empirical analysis, run:

    source("code/run_all.R")

The scripts are executed sequentially according to the workflow described in [`code/README.md`](code/README.md).

Individual scripts can also be executed separately when inspecting specific analytical steps.

## Outputs

Running the analysis pipeline generates the following outputs:

- **Figures** are saved to `figures/`.
- **Tables and numerical results** are saved to `results/`.

These outputs are generated automatically by the corresponding R scripts.

## Manuscript
